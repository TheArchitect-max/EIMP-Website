# EIMP Website

Public GitHub Pages showcase for **Engineering Intelligence & Mastery Platform (EIMP)**.

This repository is intentionally separate from the private/proprietary EIMP core. It contains only public-facing static website assets and high-level project information.

## Public boundary

Included:

- static HTML/CSS/JS;
- original local SVG artwork;
- high-level product description;
- public project status and selected public repository metrics;
- link to the TheArchitectMax portfolio HUB.

Excluded:

- proprietary source code;
- internal schemas or algorithms;
- private research artifacts;
- infrastructure details;
- credentials, secrets, tokens or environment values;
- private security configuration;
- transaction, authentication, database or SaaS runtime functionality.

## GitHub Pages

The site is designed to be served directly from the repository root through GitHub Pages. No build system, external JavaScript CDN, tracker, ad network, cookie banner, backend, checkout or authentication service is required.

Expected project URL once GitHub Pages is enabled for the `main` branch root:

`https://thearchitect-max.github.io/EIMP-Website/`

## Media provenance

No third-party image assets are used. The visual system is implemented with CSS and original SVG artwork created specifically for this project. See `CREDITS.md`.
